# Quiz App

## Project Description
The Quiz App is a simple Flutter application that allows users to answer multiple-choice questions. It contains 10 questions with four options for each question. The app checks the selected answer, displays feedback, calculates the score, and shows the final result.

## Features
- Contains 10 multiple-choice questions.
- Four options for each question.
- Displays correct and wrong answer feedback.
- Shows quiz progress.
- Calculates the final score.
- Displays the result.
- Provides a Try Again option.

## Technologies Used
- Flutter
- Dart
- DartPad

## How to Run
1. Open https://dartpad.dev/.
2. Select Flutter.
3. Copy the project code.
4. Paste it into the editor.
5. Click Run to execute the application.
